# 🎥 Screen Recorder

A lightweight, minimal screen and window recorder built with Python. Designed for efficiency, zero bloat, and fast local captures without bogging down system resources.

---

## ✨ Features

- 🎯 **Targeted Window Recording:** Capture a specific running application window or full display without needing post-crop edits.
- 🎛️ **Real-Time Brightness & Contrast Controls:** Fine-tune video exposure directly from the interface prior to capturing dark IDEs or high-glare presentations.
- ⚡ **Lightweight Architecture:** Minimal CPU and RAM footprint during active capture sessions.
- 🧵 **Non-Blocking Threading:** Responsive UI that remains smooth and stutter-free while saving recordings to disk.
- 📦 **Standard Output:** Produces standard `.mp4` / `.avi` formats playable on any media player.

---

## 🛠️ Tech Stack & Dependencies

- **Python 3.10+**
- **OpenCV (`opencv-python`):** High-performance frame capture and real-time contrast/brightness matrix math.
- **MSS / Win32 API:** Low-overhead display frame grabbing.
- **CustomTkinter / Tkinter:** Clean, minimal native GUI.
- **NumPy:** Vectorized color and luminance adjustments.
